# SuperMercado — Sistema de inventario

## Descripción del proyecto

SuperMercado es una aplicación web desarrollada con React para representar un sistema básico de inventario de un supermercado. Permite consultar productos, sus categorías, precios y unidades disponibles, además de identificar los productos que tienen poco stock.

El proyecto fue desarrollado como parte de la asignatura **Desarrollo Frontend II**.

## Tecnologías utilizadas

- React
- JavaScript
- HTML
- CSS
- React Router DOM

## Funcionalidades

- **Página de inicio:** muestra un resumen del inventario, la cantidad de productos registrados, las unidades disponibles y los productos con stock bajo.
- **Inventario de productos:** presenta el nombre, la categoría, el precio, el stock y el estado de cada producto.
- **Nuestras tiendas:** muestra información de ejemplo sobre dos sucursales.
- **Contáctanos:** presenta información de contacto de ejemplo.
- **Navegación:** permite desplazarse entre las páginas mediante un menú inferior implementado con React Router.
- **Diseño adaptable:** la interfaz se ajusta a pantallas de computador y dispositivos móviles.

## Instalación y ejecución

Para ejecutar el proyecto localmente, sigue estos pasos:

1. Clona el repositorio:

   ```bash
   git clone https://github.com/fmorice/supermercado-florencia-morice-PFY2202.git
   ```

2. Ingresa a la carpeta del proyecto React:

   ```bash
   cd supermercado-florencia-morice-PFY2202/supermercado
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia la aplicación:

   ```bash
   npm start
   ```

5. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Observaciones

Los productos, las sucursales y los datos de contacto son ejemplos utilizados con fines académicos. La aplicación no utiliza una base de datos ni guarda cambios en un servidor.
